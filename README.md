# AI 디지털 조명 생성 V3.8

## V3.8 Gemini 위치·장비 외형 수정
- Gemini 프롬프트에서 모든 X/Y 숫자 좌표 제거
- 원본과 동일 좌표계의 투명 색상점 위치 가이드 사용
- 선택된 장비 종류별 콘솔 장비 참고 이미지를 별도 첨부
- 참고 장비의 렌즈 배열·헤드·요크·베이스·하우징 비율을 유지해 사실적인 3D 장비로 재구성
- 위치점은 장비로 완전히 교체하고 최종 결과에서 제거
- 앱 헤더에 V3.8 표시를 추가해 실제 배포 여부 확인 가능

## V3.7 Gemini 합성 안정화
- Gemini에는 Position Map 이미지를 보내지 않고 원본 무대와 텍스트 좌표만 자동 전달
- Position Map의 장비 약어와 번호를 제거하고 작은 색상 위치점만 표시
- 좌표·숫자·문자·마커·UI가 결과 이미지에 출력되지 않도록 금지 규칙 강화
- 지정된 조명 장비 본체와 최소 접촉 그림자 외에는 어떤 요소도 새로 생성하지 않도록 편집 범위 고정
- 원본 무대의 구조·LED·바닥·천장·트러스·기존 장비·조명·컬러·노출을 변경하지 않도록 STAGE LOCK 강화

## V3.6 ChatGPT 자동 전달
- 정면 모드: 원본 무대 + Position Map + 완성 프롬프트 자동 입력
- 측면 모드: 센터 원본 + 측면 프롬프트 자동 입력
- 디지털 조명 AI 콘솔 익스텐션 V1.5 이상 필요
- 최종 생성 버튼은 ChatGPT에서 사용자가 직접 클릭

## V3.5 측면 생성 개선
- 센터 무대를 항상 주인공으로 유지
- 측면은 센터와 어울리는 무드·광질·재질·반사 중심의 보조 이미지로 생성
- 센터 구조의 기계적 복제는 금지하되 디자인 모티프의 단순화·확장은 허용
- 무조건 어둡거나 빈 측면을 만들지 않고 완성된 LED WALL 디자인으로 구성
- 출력 크기를 16:9로 고정하지 않고 원본과 동일한 픽셀 크기·화면비로 유지

핵심 수정
- 2D 마커를 장비 중심이 아닌 설치 접점/체결점으로 해석
- 바닥·오브젝트 상단·오브젝트 전면·트러스·바튼 설치 규칙 분리
- 측면 결과에서 정면 원본을 완전히 제외한 독립 16:9 오른쪽 패널 생성
- 물리 조명기 복제 없이 색상·광선·헤이즈·라인 조명·바닥 반사로 조명 연계
- 센터보다 단순하고 약간 어두운 측면 디자인 유지
- 좌우 대칭 중복 버그 수정
- 동일 장비 + 동일 좌표 중복 생성 차단
- 프롬프트 생성 직전 중복 자동 제거
- 화면 총 장비 수와 프롬프트 Total fixtures 일치
- ONE POSITION = EXACTLY ONE FIXTURE 규칙 강화
- AUTO 원근 / Stage Lock / Position Map 유지
- ChatGPT / Gemini 전용 프롬프트 분리
- 정면 / 측면 모드 유지
- Ctrl+V 이미지 자동 붙여넣기
- 장비 카드에는 BEAM/WASH/SPOT/TUBE/BLINDER만 표시
- 원본 이미지 화면비에 맞춰 Stage Plot을 자동 조정하여 비정형 화면비에서도 좌표 오차 방지
- 실행취소가 추가·이동·대칭·크기 변경·삭제·초기화 작업을 단계별로 복원
- 정면/측면 모드 전환 시 그리드와 버튼 레이아웃 유지

배포
- `index.html` 중심의 정적 웹앱이며 기존 Vite Vercel 프로젝트와의 호환 설정 포함
- GitHub 저장소 루트에 업로드 후 Vercel Framework Preset을 `Other`로 배포 가능
- 별도 빌드 명령이나 서버 런타임 불필요

좌우 대칭 동작
- 현재 Plot 전체를 기준으로 반대편에 없는 장비만 생성
- 이미 동일 타입/설치방식/대칭 좌표가 존재하면 추가하지 않음
- 여러 번 눌러도 수량이 폭증하지 않음
